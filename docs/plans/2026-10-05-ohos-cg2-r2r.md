## 3. 真机冷启 A/B（AMS→首帧 present_ms，每路径 3 次冷启）

| 路径 | IL（无 R2R） | R2R | Δ |
|---|---|---|---|
| JIT | 978 / 1097 / 1018（均 1031） | 680 / 719 / 732（均 710） | **−321 ms（−31%）** |
| interp | 1107 / 1089 / 1169（均 1122） | 1315 / 1265 / 1836（均 1472） | +350 ms（3 次全部慢于 3 次 IL 件） |

- 进程内 `[startup] present`（Main→首帧）：JIT 575→307 ms（−268）；interp 587→798 ms（+211）。JIT R2R 件 AMS→首帧 ≈0.71 s，接近 AOT 的 0.63–0.66 s（PERF-FINISH 口径）。
- interp 变慢定因：host 只设 `DOTNET_InterpMode=3`（`runtime-mode.txt=interp`）而**不设** `DOTNET_ReadyToRun=0`，R2R 镜像被加载但纯解释器不执行 native code → 白付 +11 MB 映射/重定位；interp run3（1836 ms、total 2041）为异常值，其余 2 次 1315/1265，方向不改。**结论：R2R 只开 JIT 路径**；interp 后续选项 = 不启用，或 host 在 interp 时置 `DOTNET_ReadyToRun=0`（**已实现并复测**，见 `2026-10-05-ohos-fixrr-consolidate.md`：runtime 对 `InterpMode>=2` 本就强制 `fReadyToRun=false`（`eeconfig.cpp:479-486`），显式行与隐式行为同效，Main→首帧回落 IL 平位；旧 +350 ms 未复现，本节归因修订为 AMS 噪声/时点差异）。
- AOT 路径不受影响：AOT 发布走 ILCompiler runtime pack，不消费 crossgen2；PERF-FINISH 的 AOT 627–663 ms 口径不变。R2R 件两路径 3×2 次运行 0 崩、pid 尾活。
