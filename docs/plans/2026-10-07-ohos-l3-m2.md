## 1) 实现面（确定性身份握手：壳 ↔ managed 双向确认）

- 壳 `Index.ets`：会话加 `generation`，子窗名 `<SUB_WINDOW_NAME>__<surfaceId>.g<gen>`；loadContent 前发布 per-child
  claim 表（AppStorage `ohos_dotnet_subwindow_claim`，LocalStorage 不可靠时的确定性回退）；新增 managed op 7
  （identity ack），`{surfaceId,id,gen}` 与 session 完全一致才写 `ohos_dotnet_subwindow_identity`；每窗回调绑定
  session 复核 liveness（迟到/关后事件不串窗、不复活）；`SUB_EVENT_*`/failure payload 全量带 surfaceId；
  suspend/resume 按 session 各发一次（device 证据日志）。
- 子页 `SubWindow.ets`：身份 = 自身窗口名（`UIContext.getWindowName()`，API12）为主，LocalStorage/claim 表交叉验证；
  冲突/无 claim → fail-closed（不挂 managed surface，PAGE_READY status=1，由 managed 定向关会话）；仅匹配 ack
  （surfaceId+gen）才挂 XComponent/输入（**错名字 → 拒绝挂载**负例）；getLastWindow 指错窗时禁拖/禁关。
- maui `OpenHarmonySubWindow`：per-surface 会话表 + 代际；PageReady 早于 Created 缓存、Created 校验后回 ack（乱序）；
  未知 id 定向 close、旧代际 ready/closed 忽略、重复不二次 ack（fail-closed）；legacy 单窗镜像零变化。
- `OpenHarmonyWindowHost`：stopped 期间 focus 事件不清 stopped（无重复 Stopped）；Suspended/Resumed 带 surfaceId
  时按窗路由；主窗路径零改动、AOT 安全（静态表/Utf8JsonWriter，无新导出）。
